# 测试数据与预期结果

所有数据均为匿名构造案例，不对应真实上市公司，不构成投资建议。两期分别设为2023和2024年度、同主体同合并范围；异常均为刻意注入。

使用方法：在网站分别导入一组文件夹里的“2023_基期.txt”和“2024_本期.txt”，填写公司与年度、确认口径，然后点击“开始核查”。**每次只导入同一文件夹的一对文件。** 详见[使用指南](../docs/使用指南.md)。

| 文件夹 | 场景 | 预期结果 |
| --- | --- | --- |
| 01_正常变化 | 指标齐全、同单位 | 4项可核算；收入+20.00%、利润−20.00%、现金流−58.33%、应收+60.00%；4项显著变化 |
| 02_缺失字段 | 本期缺经营现金流 | 3项可核算；明确提示本期缺少经营活动现金流净额；不得把缺失记成0 |
| 03_重复冲突 | 本期收入同时出现120与125亿元 | 3项可核算；营业收入被排除并提示重复或冲突；不得任取一个值 |
| 04_非正基数 | 基期利润为0、现金流为−12亿元 | 4项均有证据；利润与现金流同比“不适用”；绝对差额分别为+8亿元、+17亿元 |
| 05_跨单位换算 | 本期收入用1200000万元 | 收入仍为+20.00%；本期原值保留万元，计算结果与案例01一致 |

补充手工测试：

- 在案例01中取消口径确认：阻止运行并提示确认。
- 把基期改成2024、本期改成2023：阻止运行并提示年度需递增。
- 删去本期营业收入的“亿元”：仅该指标不能计算，明确提示缺少字段或单位。
- 确认1项、否决1项：顶部已确认数应为1/4；导出底稿分别保留人工状态。

## 规则结果与模型线索分开检查

未配置模型时，以上测试只产生规则核算和通用核查提示，不应出现假装调用LLM后的公司解释。

配置真实模型后，案例01的经营讨论可用于观察“渠道变化、信用期变化”的语义对齐。并不要求模型输出固定措辞；任何线索都必须有双期原文依据，且不能把现金流下降直接归因于信用政策。模型也可在证据不足时返回空数组。只有经过人工评估，才可记录真实线索质量。
