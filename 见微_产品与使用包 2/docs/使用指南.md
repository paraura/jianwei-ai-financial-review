# 见微使用指南

[返回产品介绍](../README.md) · [打开网站](https://report-lens-audit-1026.citrusiris5.chatgpt.site/) · [测试数据](../sample-data/README.md)

## 1. 第一次体验：使用内置示例

不需要准备财报、注册账号或配置 API。

1. 打开网站，进入“财报对比”。
2. 点击右上角 **载入示例**。页面会填入公司、2023/2024年度、两期原文、来源和口径确认。
3. 点击 **开始核查**。规则模式通常很快，不会生成模型语义结论。
4. 在结果表中查看：营业收入 +20.00%、归母净利润 −20.00%、经营现金流 −58.33%、应收账款 +60.00%。
5. 点击某一行的 **查看**。表格下方展开两期原文、来源、摘录行号和公式。
6. 在“研究线索与人工复核”区域，对指标选择 **确认已核查** 或 **标记有问题**。顶部确认数随之更新；标记有问题不计入已确认。
7. 在“研究员补充说明”中记录疑问，例如“需要核对信用期变化与期后回款”。
8. 点击结果标题右侧 **导出核查底稿**，获得 `.md` 文件，可用文本编辑器打开。浏览器可能把文件放入默认下载目录。

示例仅用于功能体验，不能据此判断真实公司经营情况。

## 2. 用测试文件体验导入

1. 下载并解压本包，打开 `sample-data/01_正常变化/`。
2. 在网站填写公司“测试企业（构造）”，基期2023、本期2024。
3. 基期区域点击 **选择文件**，选 `2023_基期.txt`；本期选 `2024_本期.txt`。
4. 导入后，原文自动填入文本框，来源自动变为文件名及“用户提供，真实性未验证”。这是可编辑的，可补充“构造测试案例”。
5. 阅读并勾选口径确认，再点击 **开始核查**。
6. 根据[测试数据说明](../sample-data/README.md)比对预期结果。

不要上传 ZIP 到网站文本框；这里接收的是解压后的 TXT 文件。

## 3. 用自己的财报摘录

### 选择可比材料

使用同一公司两期年度、同一合并范围的财报。若有追溯重述，应使用重述后的基期数值。不要混用半年报与年报、单季与累计、母公司与合并报表。

### 当前输入格式

目前是窄范围规则提取，**不能直接理解任意财报表格**。请把所需原始字段整理为每行一项，并保留对应出处。需要调整标签或换写单位时，在来源或复核意见中注明；证据行号指输入摘录的位置，不是PDF页码。

```text
营业收入：100亿元
归母净利润：10亿元
经营活动现金流净额：12亿元
应收账款：20亿元
经营讨论：在此粘贴相关原文。
```

支持数值后的单位：`元`、`万元`、`亿元`。指标名后使用冒号或空格。每项指标只能出现一次；包含两期值的整张表格可能引发重复或误读，不适合直接粘贴。

“出处”填写报告名称、实际披露日期、原始页码、链接和必要口径说明。例如：“某公司2024年年度报告，披露日期YYYY-MM-DD，第XX页，合并报表，金额单位万元，原始链接”。这些信息由使用者核实，产品不会自动验证。

单期上限30,000字符；TXT文件上限120,000字节。直接上传PDF不受支持。模型模式的供应商上下文上限可能更低。

## 4. 如何理解结果

- **同比**：先统一到元，再按（本期−基期）÷基期计算，仅适用于正基数。
- **显著变化**：同比绝对值≥20%的演示标记，表示优先核查，不表示投资风险等级。
- **基数非正**：基期为零或负数，不显示常规同比。点击证据查看差额。
- **部分结果**：有缺失、缺单位或重复字段，只计算满足条件的指标，不代表整份财报正常。
- **规则演示**：未调用LLM，不会根据经营讨论生成个性化语义解释。
- **LLM成功**：结构和引文匹配通过，但假设仍需人工判断。
- **LLM失败**：保留规则核算并显示失败信息，不把失败伪装成正常模型结论。

看到收入增长、现金流下降时，先核查而不是直接归因。模型提出的联系也需要财报附注、经营资料等进一步支撑。

## 5. 人工复核、导出与本地记录

“确认已核查”表示你已核对该数值及依据；“标记有问题”表示待处理。建议在补充说明中写清指标、问题、需要补查的材料。模型线索目前没有单独的逐条确认按钮，可在补充说明中记录接受或否决原因。

导出底稿包含两期来源、原值、同比、引文位置、人工状态、意见、异常及执行轨迹。尚未核查的项目会保留“待复核”，不自动变成已确认。

点击 **保存到本机核查记录**，保存任务摘要与反馈；完整原文不保存在该记录中。通过 **本地核查记录** 查看或清除。不同浏览器不共享，清理浏览器数据后会丢失。

重新点击“开始核查”会清空上次任务的复核状态与说明；编辑输入后应重新运行，旧结果不会自动跟着更新。需要保留的底稿请先导出。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| “请先确认同主体…” | 人工检查两期口径后，再勾选确认框 |
| 指标显示缺失 | 检查标签、冒号、数值和单位是否符合上面的格式 |
| 显示重复或冲突 | 每个指标只保留一条，冲突时回原始财报核实，不要随意删掉差异 |
| 没有AI解释 | 当前在线版本未配置模型，属于预期行为；TXT导入不会启用模型 |
| 导出后没看到文件 | 检查浏览器下载列表与默认下载目录 |
| 结果与修改后的输入不一致 | 修改输入后重新运行；先导出需保留的旧结果 |
| 自己的真实数据与测试数值不同 | 测试仅为构造案例；按实际原文核对，不能套用预期百分比 |

## 7. 数据使用提醒

规则模式在浏览器处理文本。接入模型后，原文会发送到所配置的模型供应商。只提供有权使用的信息，不输入私人持仓、密钥或未授权非公开资料。模型接入与隐私配置见[开发与模型配置](开发与模型配置.md)。
