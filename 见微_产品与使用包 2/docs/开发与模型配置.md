# 开发与模型配置

## 本地运行

需要Node.js 22+，无第三方运行依赖。在仓库根目录：

```sh
node scripts/assemble.mjs
node scripts/dev.mjs
```

打开 http://localhost:4173 。编辑src后重新assemble并重启服务。worker/index.js是生成文件，不在源码包中；构建脚本会自动创建。

```sh
npm test
npm run build
node scripts/validate-artifact.mjs
```

部署产物为dist/server/index.js，运行于Worker ESM环境。.openai/hosting.json不绑定在线站点ID，自行托管时配置自己的项目，避免误操作原站。

## 可选模型接口

配置以下服务端环境变量才能启用LLM，默认不配置：

| 变量 | 用途 |
| --- | --- |
| MODEL_API_KEY | 模型供应商密钥，只保留在服务端 |
| MODEL_ENDPOINT | 可信供应商的完整HTTPS Chat Completions兼容地址 |
| MODEL_NAME | 供应商支持的模型名称 |
| PORT | 本地端口，默认4173 |

项目不自动加载.env，使用进程环境或托管secret设置；.env.example仅列变量名。不要把密钥上传GitHub、写进浏览器或发到聊天。托管环境变量更新后需部署使之生效。

模型端点需要支持messages及choices[0].message.content结构，content为含insights数组的JSON；每条含hypothesis、oldQuote、newQuote、question。接口实现见src/server.js，实际供应商兼容性尚未验证。

服务端超时28秒、客户端35秒；单期最多30,000字符。上下文限制、并发、供应商成本需另行评估。引文匹配、结构约束和关键词过滤是基础措施，不是完整合规或注入防御。公开站接入真实密钥前，需补齐鉴权、配额及限流；当前公开站没有模型密钥。

## 数据与隐私

规则模式仅在浏览器处理原文；模型模式把原文发送至配置供应商。无应用级服务端数据库和原文日志，托管及供应商平台可能记录请求元数据。localStorage仅保存最近20条任务摘要与意见。不要输入未授权非公开信息，复核意见也不应包含敏感持仓。
