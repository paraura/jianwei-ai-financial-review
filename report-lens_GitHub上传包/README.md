# 见微 · 财报变化核查工作台

面向初级基本面研究员，将两期年度财报摘录转为可追溯、可复核的变化底稿。校招题目 14 的可运行演示作品。

## 在线体验

[打开见微工作台](https://report-lens-audit-1026.citrusiris5.chatgpt.site/) · 已公开，无需登录。点击“载入示例 → 开始核查”体验。示例均为构造数据。

## 完成度声明

已实现：双期 TXT/粘贴输入、统计口径人工确认、四指标规则抽取、单位换算、确定性同比计算、逐行证据、数据缺失/冲突提示、人工确认/否决、Markdown 导出、本机摘要记录、服务端模型适配与输出校验。

当前运行模式：未配置模型 API，默认规则演示，未执行真实 LLM 推理；示例为构造数据。模型成功、失败与违规输出的测试使用模拟响应，不代表真实模型质量。此状态不能宣称已完成 AI Native 能力验证。

## 启动

需要 Node.js 22 或更新版本，无第三方依赖。

```sh
node scripts/assemble.mjs
node scripts/dev.mjs
```

打开 http://localhost:4173 ，点击「载入示例」→「开始核查」→「查看」→确认或否决→导出底稿。

```sh
node --test tests/core.test.mjs
bash scripts/build.sh
node scripts/validate-artifact.mjs
```

修改 src 后重新 assemble、测试并重启本地服务。worker/index.js 是生成文件。部署为 Cloudflare Worker ESM，构建文件位于 dist/server/index.js。

## 环境变量

默认无需环境变量。启用模型需在服务端设置以下三项，浏览器不接收密钥：

- MODEL_API_KEY：模型供应商密钥。
- MODEL_ENDPOINT：完整 HTTPS Chat Completions 兼容接口地址；必须是可信模型供应商。
- MODEL_NAME：供应商支持的模型名称。
- PORT：可选，本地端口，默认 4173。

本地可在进程环境中配置；项目不会自动加载 .env。托管时配置服务端 secrets，再重新部署。不要把密钥写入代码、仓库、截图或聊天。模型接口兼容性未通过真实供应商端到端验证；不兼容会显式报错并保留规则结果。

## 产品选择与 AI 的角色

用户任务：年报发布后对比同一公司两期财报，将变化与原文交给资深研究员复核。规则负责已知标签抽取与计算；LLM 负责经营表述语义变化与待核查问题。跨期文本对齐相对规则具备潜在增量，但尚待真实用户盲评，不以“使用了模型”替代价值证明。

AI 输入是原文与工具计算结果；输出最多 3 条带跨期引文的研究线索。服务端检查结构、逐字引文和高风险建议词；模型输出依旧为待核查推断。提示词注入和违规词变体不能仅靠这些检查彻底解决，需人工复核。

## 数据来源与边界

演示数据为匿名构造，不冒充真实公司。自定义文本与来源由用户提供，来源真实性、披露时点、合并范围、重述口径需要人工核实。支持营业收入、归母净利润、经营活动现金流净额、应收账款四项，标签后需有冒号/空格、数值及元/万元/亿元单位。只适用于两期年度合并报表的明确标签摘录。

重复、缺失字段禁止计算对应指标；零或负基数仅给绝对额变化，禁止常规同比。20% 为演示核查阈值，不是经实证优化的风险模型。没有自动识别真实报表表头、PDF、OCR、合并口径和财务重述。

未接通扶摇、iFinD；文档访问尝试未能读取，不宣称有相关工具调用。核心流程以原始财报证据为主，不需要行情快照。后续优先以扶摇财务字段校验数值、iFinD 新闻提供补充事件证据；仍需原始公告核验。

## 风险、隐私、成本

不生成直接买卖建议、确定性涨跌预测或收益承诺。源文本在规则模式下只在浏览器处理，模型模式会发至配置供应商。无服务端数据库和应用级原文日志；托管/供应商平台可能记录请求元数据，需遵守其策略。localStorage 只存最近20条任务摘要与反馈，不存完整原文；反馈不要填写私人持仓或未授权非公开信息。

模型调用超时 28 秒，客户端超时 35 秒；单期文本最多 30,000 字符，可能超过某些供应商上下文，应进一步分段。暂未实现公开环境的鉴权、配额和调用限流；公开接入真实模型前必须补齐，当前公开网站没有配置模型密钥；接入真实模型前须完成鉴权、配额及限流。自动合规检查只是一层防护。
