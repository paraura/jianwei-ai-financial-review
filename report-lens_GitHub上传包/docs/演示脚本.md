# 90秒演示脚本（可选录制，当前未录视频）

0–15秒：见微面向初级基本面研究员。年报更新后，我们需要找到变化，并把依据交给主管复核。它输出研究底稿，不做股票推荐。

15–35秒：载入构造示例，介绍两期来源与统计口径确认。明确当前无模型API，运行的是规则演示；真实AI适配已准备，但没有完成质量验证。

35–55秒：点击开始核查。营业收入增长20%，归母净利润下降20%，经营现金流下降58.33%，应收账款增长60%。这些是确定性计算，不等于已经解释经营原因。点击查看原文，说明出处、行号和公式。

55–75秒：人工确认一项、标记另一项有问题，写下需要补充核查的说明。导出带证据和人工状态的底稿。

75–90秒：演示删除某字段后出现部分失败。最后说明真实LLM将用于跨期经营表述变化，模型必须提供双期逐字引文；下一步通过真实用户对照评测，验证效率与线索质量。

录制前应自己完成一遍，不要朗读没有真实做过的效果数据。
